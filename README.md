# E-commerce Funnel Analysis

## Overview
An exploratory data analysis project focused on understanding customer behaviour across the e-commerce purchase journey, identifying conversion patterns, and exploring factors influencing purchases and checkout abandonment.

## What's Included
- **Funnel Analysis:** Conversion rates and drop-offs across the purchase journey.
- **Customer Behaviour:** Product category, channel, and regional purchase analysis.
- **Checkout Abandonment:** Abandonment rates and device-wise comparisons.
- **Time Analysis:** Browsing and purchasing patterns by hour and day.
- **Visualizations:** Charts highlighting revenue distribution and purchase timing.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib

## Objective
To uncover meaningful insights into customer purchasing behaviour and identify opportunities to improve the e-commerce conversion journey.

## Dataset
The Dataset used is from Kaggle
